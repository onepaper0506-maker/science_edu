# 한입의 여행 · 소화 탐험실

중학교 과학의 소화계 구조·소화·흡수를 기관별로 관찰하고 확인하는 정적 웹 앱입니다. 내용 기준은 비상교육 중학교 과학 2, 194–199쪽입니다. 교과서 PDF와 원본 그림은 배포 파일에 포함하지 않습니다.

## 실행

추가 설치나 빌드, API 키, 데이터베이스가 필요하지 않습니다. 저장소에서 Python 3으로 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory .
```

브라우저에서 서버의 첫 화면을 엽니다. ES 모듈을 사용하므로 HTML 파일을 직접 여는 대신 HTTP 서버를 사용하세요. GitHub Pages에는 이 저장소의 루트를 배포하면 됩니다. 실제 원격 배포는 별도로 수행해야 합니다.

## 학습 흐름

- 왼쪽 소화계 그림과 버튼으로 소화관 6곳, 소화샘 4곳을 선택합니다.
- 오른쪽 과정 버튼으로 총 17개 과정의 확대 모형·관찰 질문·핵심 설명을 확인합니다.
- 모형은 반복 재생, 일시 정지, 다시 보기를 지원합니다. 키보드 조작, 모바일 화면, 움직임 줄이기 설정을 지원합니다.
- 기관별 2문항, 총 20문항을 제출하면 해설과 관련 과정으로 돌아가는 버튼을 제공합니다.
- 첫 응답과 최근 응답, 재도전 횟수를 구분합니다. 미응답은 오답과 별도로 표시합니다.
- 10개 빈칸을 직접 완성하는 정리표와 기관별 학습 기록을 제공합니다.
- 보고서 제출 화면에서 학년·반, 번호, 이름과 주관식 6문항의 답변을 작성합니다. 보고서 PDF 내보내기 버튼으로 인쇄 창을 열고 대상을 PDF로 저장으로 선택합니다.
- 보고서에는 선택형 20문항의 문제·첫 응답·최근 응답·정답·제출 횟수, 주관식 답변 전체, 열어 본 과정, 정리표가 포함됩니다. 주관식은 자동 채점하지 않으며 교사 평가란을 제공합니다. 작성 중인 정리표와 미응답도 명시합니다.
- 학생은 저장한 PDF를 교사가 안내한 제출처에 직접 제출합니다. 자동 제출 서버나 교사 계정은 필요하지 않습니다.
- 열어 본 과정은 이해도 평가와 별도로 표시합니다. 학생 정보와 주관식 답변을 포함한 기록은 브라우저 localStorage에만 저장하며 서버로 전송하지 않습니다. 기록 화면에서 전체 삭제가 가능합니다. 저장 불가 시 현재 세션에서만 작동합니다.

기존 호흡·배설 앱은 `body-lab.html`에 보존했으며 하단 링크로 이동할 수 있습니다.

## 검증

Node.js 22 이상으로 의존성 설치 없이 기존 로직 검증을 실행합니다.

```sh
npm test
```

검증 범위: 기관·과정·문항 연결, 미응답 구분, 첫 응답 보존과 재도전 점수, 정리표 채점. 실제 브라우저에서 기관 선택, 모든 과정 모형, 정답·오답·재도전, 저장 복원, 기록 삭제, 정리표, 키보드, 모바일 화면도 확인해야 합니다.

## 파일

- `index.html`: 첫 화면
- `src/app.js`: 화면과 상호작용, 기록 저장·복원
- `src/content.js`: 교과서에 맞춘 학습 내용과 평가 로직
- `src/graphics.js`: 소화계 및 과정별 SVG 모형
- `src/report.js`: 주관식 문항, 학생 보고서 생성, 입력값 처리
- `src/style.css`: 반응형 화면, 모형 애니메이션, 인쇄 스타일
- `test/learning.test.js`, `test/report.test.js`: 학습·평가·보고서 로직 검증

모형의 기관 크기·반응 속도·분자 수는 실제 측정값이 아닙니다. 지방 유화와 효소에 의한 화학적 분해를 구분하며, 최종 소화 산물은 지방산과 모노글리세리드로 표시합니다. 위는 소화관이면서 위액 분비 기능도 담당하고, 물은 작은창자와 큰창자 모두에서 흡수됩니다. 교사에게 기록을 전송하는 기능이나 별도의 침 실험 시뮬레이터는 포함하지 않습니다.

Playwright Python과 Chromium이 설치된 환경에서는 서버를 실행한 상태에서 전체 브라우저 검증도 재실행할 수 있습니다.

```sh
python3 test/browser_smoke.py
```

이 검증은 `/usr/bin/chromium`과 로컬 8000번 서버를 사용합니다. 별도의 브라우저 컨텍스트에서 모든 17개 과정과 20개 문항, 정리표 오답·수정, 새로고침 복원, 기록 삭제, 키보드, 390px 화면, 움직임 줄이기 설정을 확인합니다. 화면 캡처는 `/tmp/digestion-validation/`에 저장합니다.

PDF 보고서의 실제 출력 검증은 Playwright Python, Chromium, PyMuPDF가 설치된 환경에서 실행합니다. 한글 학생 정보와 실제 선택 답변, 긴 주관식의 마지막 문장까지 A4 PDF에 포함되는지 확인합니다. 테스트 데이터는 별도 브라우저 컨텍스트에서만 작성됩니다.

```sh
python3 test/report_browser.py
```

생성한 검증용 PDF는 `/tmp/digestion-report-validation/student-report.pdf`에 저장합니다. 웹 앱은 별도 PDF 라이브러리 없이 브라우저의 PDF 저장 기능을 사용합니다.
